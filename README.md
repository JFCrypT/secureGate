# secureGate

Sistema de control de acceso seguro para el ingreso al Laboratorio de Mecatrónica de la Facultad de Ingeniería del Ejército.

El proyecto implementará inicialmente un prototipo de reconocimiento facial sobre Raspberry Pi 3 y ESP-CAM, incorporando desde el diseño criterios de ciberseguridad, protección de datos biométricos, gestión segura de claves, auditoría y hardening.

Posteriormente se prevé su integración con la infraestructura de control de acceso existente en el laboratorio.
